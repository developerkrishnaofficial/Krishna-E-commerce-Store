# Krishna E-commerce Store 🛒

A fully responsive front-end **e-commerce fashion store** for jackets and fashion wear, built using **HTML, CSS, and JavaScript** — no backend and no frameworks.

🔗 **Live Site:** [developerkrishnaofficial.github.io/Krishna-E-commerce-Store](https://developerkrishnaofficial.github.io/Krishna-E-commerce-Store/)

---

## ✨ Features

* 🖤 **Black Navigation Bar** with a bold **Red** theme
* 🌙 **Dark Mode / Light Mode** toggle with saved preference
* 🎡 **Spin & Win Discount Wheel** — first-time users get one free spin for an automatic cart discount of **5–25% OFF**
* 🔐 Simple client-side **Login / Signup** system
* 🧥 **Jacket Collection** — Bombers, Varsity & Leather Jackets for Men and Women
* 🆕 **New Arrivals** & **Trending Now** product sections
* 🛒 **Shopping Cart** with automatic discount calculation
* 🔍 **Product Details** page with image zoom effect
* 📄 Dedicated **About**, **Terms & Conditions**, and **Contact** pages
* 📱 Fully **responsive** design for mobile, tablet, and desktop
* 💰 Prices displayed in **Indian Rupees (₹)**

* **HTML5** — Semantic page structure

## 🚀 Running Locally

No build step is required because this is a static HTML, CSS, and JavaScript project.

### 1. Clone the repository

```bash
git clone https://github.com/developerkrishnaofficial/Krishna-E-commerce-Store.git
```

### 2. Open the project

Open `index.html` directly in your browser.

### Or use a local server

```bash
npx serve .
```

Then open the generated `localhost` URL in your browser.

## 🎡 How the Spin & Win Wheel Works

1. Create a new account from the **Sign Up** page.
2. After login, the **Spin & Win** option becomes available.
3. Spin the wheel to receive a discount or **Try Again** result.
4. The discount is automatically saved.
5. The discount is applied to the **Cart** total.
6. Each user gets **one free spin**.

> **Note:** Login, signup, cart, theme, and discount functionality are implemented on the client side using JavaScript and `localStorage`. No backend or database is used.
